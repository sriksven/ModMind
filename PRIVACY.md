# ModMind Privacy Policy

Last updated: May 24, 2026

ModMind is a Reddit Devvit moderation tool for subreddit moderators.

## Data Processed

ModMind may process Reddit posts, comments, subreddit rules, moderator actions, and app settings needed to provide moderation suggestions, weekly digests, rule gap analysis, and multilingual moderation support.

## AI Processing

When AI evaluation is enabled, ModMind sends relevant post or comment text, subreddit rules, and limited moderation context to OpenAI to generate moderation suggestions. ModMind does not sell user data.

## Storage

ModMind stores moderation evaluation results, aggregate statistics, cached subreddit rules, language metadata, and moderator action history in Reddit Devvit Redis storage for the installed subreddit.

## Use of Data

Data is used only to operate ModMind's moderation features, improve subreddit-specific moderation context, and generate moderator-facing summaries.

## Access

ModMind is intended for use by subreddit moderators. Moderator-facing outputs may include AI-generated reasons, suggested actions, and summaries of moderation activity.

## Contact

For questions about this policy, contact the app developer through the ModMind GitHub repository or Reddit developer profile.
